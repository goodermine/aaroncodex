# Memory index

Durable facts, preferences and corrections learned from working sessions —
one small markdown file per fact in this folder, indexed here. Read this at
session start (CLAUDE.md points here). Updated by the `/dream` routine
(`.claude/skills/dream/SKILL.md`): proposals only, applied on Aaron's approval.

**Why this lives in the repo and not `~/.claude/`:** sessions run in ephemeral
containers — the home directory is reclaimed, the repo is pushed. A memory that
is not committed does not exist.

Rules (mirrored in the skill):
- One fact per file, named `NNN-short-slug.md`, listed here with a one-line gist.
- Every fact records its evidence (session date + a short quote).
- Facts are never deleted, only marked `status: retired` with a reason —
  the same convention as everywhere else in this repo.
- Nothing lands here without Aaron's explicit approval, except typo/index
  repairs.
