Concise product summary of aaroncodex, for cross-repo context and for
sale/pitch conversations (see 027): a proprietary vocal-analysis + cleanup
toolkit. Core IP is the deterministic scoring engine (`analyse_song.py`,
Rubric v5, 7 acoustic components) calibrated against a real 50-track
professional reference pack ("10 = a typical pro"; every number measured, never
LLM-generated). Plus VoxPolish (transparent, editable cleanup + tuning),
VoxSuite (fused FastAPI server), pitchmonitor, and a ~764k-word original
vocal-pedagogy knowledge base. Maturity: the scoring engine is production-ish
and well-tested; overall it is single-user, no auth, pre-revenue, no CI.

> evidence: README — "VoxPolish repairs and polishes a vocal, while Vox analysis measures and scores it"; "calibrated to 50 professional reference vocals — 10 = a typical pro" — session of 2026-08-09
