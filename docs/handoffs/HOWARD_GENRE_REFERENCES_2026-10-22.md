WHAT THIS IS
Singnexa scores singers against professional vocals. We're building a
yardstick for each genre (rock'n'roll, blues, hard rock, rap), so we need the
ORIGINAL studio recordings below. They're for analysis only: each one is
separated, measured, and then the audio is DELETED. Nothing gets published or
shared.

This ONE list replaces the earlier "10 oldies" request, so nothing is fetched
twice. If you've already started the oldies, carry on and skip any duplicates.

WHERE TO PUT THEM
Dropbox › Song_Analysis › Originals for analysis - DELETE AFTER
(the same folder as last time; leave the files already in there alone)

RULES (same as the 16 Oct batch)
1. The ORIGINAL studio recording by the original artist. No live versions,
   covers, re-recordings, karaoke, "remastered with new vocals", radio
   edits that cut verses, or sped-up/slowed versions.
2. Best quality you can get. Lossless WAV/FLAC first, otherwise the
   highest-bitrate source. Don't re-encode lossy to WAV and call it lossless.
   Record the real source format.
3. Name each file: Artist - Title (original).ext
4. Add one line per file to PROVENANCE.txt in that folder:
   file | source | format | duration | SHA-256
5. If you can't find a clean original, SKIP it and list it at the end with
   the reason. Don't substitute a different version.
