# Handoff — Back to Black, Rilda: deliberate stylistic slides, not a pitch fault

## Context (from Aaron directly)

The scooping/sliding into notes measured on Rilda's 27 Sep 2026 "Back to
Black" take was a **deliberate stylistic choice**, matching the soulful,
slide-heavy delivery of the original Amy Winehouse recording — not an
accuracy problem.

Documented here so a future reading of this take's onset-accuracy numbers
isn't misread as a technique fault. Same pattern as
`docs/handoffs/HANDOFF_ALL_THAT_SHE_WANTS_SEP16220_CONTEXT.md` and the
"Things That Make You Go Hmm" register-change note in
`HANDOFF_SESSION_2026-09-06.md` §6 — and the same distinction CLAUDE.md
and Aaron's own improvement brief already draw elsewhere: scooping is only
a flaw when it's a habit, not when it's chosen on purpose as style.

## What the numbers show

- Archive JSON: `voxanalysis/archive/scratch-analyses/2026-09-27-rilda-back-to-black-take-001_analysis.json`
- Overall: 6.8/10, Capture-fair: 5.9/10
- Onset accuracy (diagnostic, not scored): **35.8% of note entries scooped**,
  median scoop depth -85.2 cents — the highest scoop rate of Rilda's three
  takes from this session.
- Held-note stability was still the primary scored focus (0.0, 88.4 cents
  drift) — that component measures notes *after* landing, not the approach,
  so it is unaffected by this context and remains a genuine growth edge.

## What this does and doesn't change

- **Does not change any score.** The engine measures what happened
  acoustically; a stylistic choice still produces the same numbers a
  technique habit would. This note only changes how a human reader should
  *interpret* the onset-accuracy figures for this specific take.
- **Does not excuse held-note stability.** That's a different measurement
  (drift after the note is already sustained), unrelated to how the note
  was approached, and still worth working on regardless of style intent.
- If Rilda sings this song again and the scoop rate stays similarly high,
  that's still worth a listen either way — deliberate style should be
  consistent and controlled, not indistinguishable from an unplanned habit.
