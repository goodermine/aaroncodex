# Sources

Reference lists extracted from the research documents in this library.

Each file here corresponds to one document elsewhere in the repo and holds the
`Works cited` block that originally sat at the foot of it. The bodies of those
documents are now clean prose; nothing was deleted, only moved.

**Why they are separated.** These lists are the audit trail from the original
research, not part of the written knowledge. Keeping them out of the main documents
makes the library readable and keeps a training corpus free of thousands of raw URLs
— while preserving the ability to check where a claim came from.

**Format.** As-extracted. Run-on numbered lists with escaped characters, inherited
from the original Word exports. These are an archive to search, not documents to read.

Exclude this folder from any training corpus.
